# Bakhita-portfolio
It is a portfolio website that showcases my web development projects and  techinical skills
## Live Demo link
https://github.com/bakhita579/Bakhita-portfolio
## Features List
 
 - Navigation Bar  - a vertical navigation bar linking about,skills,project and contacts sections of the page.
 - Projects - projects are stored as a JavaScript array of objects and rendered dynamically onto to the page.
 - About me - contains an avator and personal bio.
 - Skills - hightlighted a list of skils like HTML, CSS and JavaScript that are rendered on to the page using Javascript.
- Contact section- a display of the email and a direct link to the Github profile.
## Technologies Used
* HTML - used for the page structure and sematic elements
* CSS - used for layout styling like font and background color, flexbox and responsive design
* JavaScript - for dynamic rendering of the skills and projects onto the page using array of objects to enter data.
## How to run locally 
To run run this project i your local machine, follow the following steps.
1. **Clone the repository on your terminal**
```bash
git clone: https://github.com/bakhita579/Bakhita-portfolio 
```
2.  **Open the project folder in your code editor such as VS code.**
3. **Run with a live server**
    1. Open the index.html file
    2. If you are using VS code click the **Go live Button** on the right and select open with live server
